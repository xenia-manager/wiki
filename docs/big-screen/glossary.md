# Glossary

Terms a newcomer meets on page one of every other document here.

| Term | Meaning |
|---|---|
| GPD | Game Profile Data file. Per-game achievement and statistics storage read from the active profile or the game's own file |
| XUID | Xbox user ID. Profiles are matched and persisted in hex form |
| XConfig | Xbox system configuration file per emulator version, holding display resolution, default profile, language, and country |
| Title update | Installable game patch package listed in the Title Updates pane |
| Marketplace content | Installable add-on package listed alongside title updates |
| Patch file | Per-game patch TOML describing available patches and their enabled flags |
| Content slot | A config entry pointing the emulator at the active profile for launch |
| Overlay | A full-window screen revealed over the Dashboard and lifted on Back |
| Pane | The right-hand panel inside the game modal previewing the selected option |
| Option | One row in the game modal's left action list or the Dashboard's action row |
| Canary | Mainline emulator build, one of the managed versions |
| Mousehook | Emulator build carrying mouse input support |
| Netplay | Emulator build carrying online play support |
| Custom | User-supplied emulator build with no standard folders, excluded from managed paths |
